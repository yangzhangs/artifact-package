## AI policy

The responsible use of AI tools is recognised, but it is subject to the
following policy on acceptable and unacceptable usage.

---

### Acceptable usage
- Assist with code changes and documentation on condition you understand and can
  explain them on request.
- Drafting for non-native English speakers (grammar/clarity).
- Understanding existing code.
- Speed up the workflow and automate routine coding tasks.
- Code review to find bugs at an early stage.

---

### Unacceptable usage
- Using AI tools whose terms and conditions restrict the use of output in a way
  that conflicts with open source standards.
- Fully-automated submissions without a human-in-the-loop: PRs, issues,
  discussions.
- Submitting code you haven't personally tested or reviewed.

**Happy hacking!** 🍻
