## <mark>AI/LLM Usage Policy</mark>

<mark>We allow and encourage AI-assisted contributions, but we maintain high standards for code quality:</mark>

- <mark>**Allowed AI/LLM usage**:</mark>
  - Code generation assistance
  - Documentation writing
  - Test case generation
  - Refactoring suggestions
  - Debugging help

- <mark>**Guidelines for AI-assisted contributions**:</mark>
  - <mark>Review and understand all AI-generated code before submitting</mark>
  - <mark>Test all AI-generated code thoroughly</mark>
  - <mark>Ensure AI-generated code follows our code style and architecture</mark>
  - <mark>Properly attribute AI assistance in commit messages</mark>
  - <mark>Be prepared to explain and defend any AI-assisted code</mark>

- <mark>**What we consider "AI slop" (not acceptable)**:</mark>
  - <mark>Blindly pasting AI-generated code without review</mark>
  - Code that doesn't follow project conventions
  - <mark>Poorly tested or buggy AI-generated solutions</mark>
  - Unnecessary or overly complex implementations
  - Boilerplate comments or unhelpful documentation
  - Solutions that don't actually solve the problem

<mark>All contributions, whether AI-assisted or not, are subject to the same quality standards and review process.</mark>
