## <mark>AI Assistance Notice</mark>

> [!IMPORTANT]
>
> <mark>If you are using **any kind of AI assistance** to contribute to jsrepo,</mark>
> it must be disclosed in the pull request.

<mark>If you are using any kind of AI assistance while contributing to jsrepo,</mark>
**this must be disclosed in the pull request**, along with the extent to
<mark>which AI assistance was used (e.g. docs only vs. code generation).</mark>
<mark>If PR responses are being generated by an AI, disclose that as well.</mark>
As a small exception, trivial tab-completion doesn't need to be disclosed,
so long as it is limited to single keywords or short phrases.

An example disclosure:

> <mark>This PR was written primarily by Claude Code.</mark>

Or a more detailed disclosure:

> <mark>I consulted ChatGPT to understand the codebase but the solution</mark>
> was fully authored manually by myself.

Failure to disclose this is first and foremost rude to the human operators
on the other end of the pull request, but it also makes it difficult to
determine how much scrutiny to apply to the contribution.

<mark>When using AI assistance, we expect contributors to understand the code</mark>
that is produced and be able to answer critical questions about it. It
isn't a maintainers job to review a PR so broken that it requires
significant rework to be acceptable.

<mark>Please be respectful to maintainers and disclose AI assistance.</mark>
