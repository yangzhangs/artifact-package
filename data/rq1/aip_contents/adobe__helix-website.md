## <mark>AI-Generated Contributions</mark>

<mark>If your pull request contains code that was generated or co-authored by AI tools (such as GitHub Copilot, ChatGPT, Claude, or similar), you must apply the `ai-generated` label to your pull request.</mark>

This helps maintainers understand the context of contributions and ensures appropriate review processes.

Each commit message that is not part of a pull request:

* Should contain the issue ID like `#123`
* Can contain the tag `[trivial]` for trivial changes that don't relate to an issue
