## <mark>AI Policy</mark>

*This policy was adapted from `pygfx`, `scikit-learn`, and `SciPy`*

<mark>While we recognize that LLMs may be useful, at our core, we are a small team of developers who enjoy discussing code written by other humans.</mark>
<mark>As such, our preference is that contributions are written without the use of AI.</mark>

---

### Responsibility

<mark>You are responsible for all the code that you contribute, including AI</mark>
generated code. You must understand and be able to explain the submitted code as
well as its relation to existing code. It is not acceptable to submit a
PR for code that you cannot understand and explain yourself.

---

### Disclosure

<mark>You must disclose whether AI has been used to produce any code of your</mark>
pull-request. If so, you must document which tool(s) have been used, how they
<mark>were used, and specify what code or text is AI generated.</mark>

---

### Copyright

Contributors must own the copyright of any code submitted to `fastplotlib`. Code
<mark>generated by AI may infringe on copyright and it is your responsibility to not</mark>
infringe. We reserve the right to reject any pull requests where the copyright
is in question.
