## <mark>Contributing with AI-generated code</mark>

<mark>As artificial intelligence evolves, AI-generated code is becoming valuable for many software projects, including</mark>
<mark>open-source initiatives. While we recognize the potential benefits of incorporating AI-generated content into our</mark>
open-source projects there a certain requirements that need to be reflected and adhered to when making contributions.

Please see
<mark>our [guideline for AI-generated code contributions to SAP Open Source Software Projects](https://github.com/SAP/.github/blob/main/CONTRIBUTING_USING_GENAI.md)</mark>
for these requirements.
