## <mark>AI generated code</mark>

* <mark>Submissions where any of the code is AI generated must be marked with [AI generated].</mark>

<mark>(When code is generated by prompting either directly to an LLM or through "comment prompting".)</mark>
  
* Not needed when AI suggestions is used in "autocomplete" mode only for boilerplate or other repetitive code.
  
* <mark>Failure to disclose the use of AI in a PR will result in a closed PR and deliberately trying to obfuscate the use of AI will result in your account getting blocked from contributing again.</mark>

* <mark>"Vibe coded" PR's where it seems like the author doesn't understand the generated code will be dismissed.</mark>
