## Before Opening a PR

- <mark>AI-assisted coding is welcome. Maintainers also use AI.</mark>
- For new features, please open a feature request issue first.
- <mark>Please review AI-generated changes yourself before submitting.</mark>
- <mark>Keep the code clean: remove AI-generated noise, duplicated code, and unnecessary comments.</mark>
- Comments should be minimal and useful. Avoid obvious or verbose comments.
- If a PR is very large and not self-reviewed, we may ask for cleanup or splitting before review.
