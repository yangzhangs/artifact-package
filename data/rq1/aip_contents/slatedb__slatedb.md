## <mark>AI Generated Pull Requests</mark>

<mark>AI-generated (or largerly generated) pull requests are welcome, provided that you:</mark>

- <mark>Disclose that the pull request is largely AI generated.</mark>
- Specify which tool and model you used.
- Understand the changes in the PR.
- Keep PR descriptions and review replies human.
- Review the code change yourself before submitting the PR.
- <mark>Run `/review` locally in the `codex` or `claude` CLI before submitting the PR.</mark>
- Follow the guidelines in the PR template (the checkboxes at the bottom).
