### <mark>2. Be Cautious With AI-Generated Code</mark>
> <mark>AI tools (like GitHub Copilot or ChatGPT) are helpful but **not always context-aware**.</mark>
<mark>**Please DO NOT blindly copy-paste AI-generated code.**</mark>
Before committing:
- Double-check if the code aligns with our project’s architecture.
- Test thoroughly to ensure it doesn’t break existing functionality.
- Refactor and adapt it as per the codebase standards.
