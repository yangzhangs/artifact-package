### <mark>AI use disclosure</mark>

<mark>We welcome the use of AI tools (such as GitHub Copilot, ChatGPT, Claude, etc.) to assist with contributions.</mark>
However, please keep the following in mind:

* <mark>**You are responsible for AI-generated code.**</mark>
  Review all AI output for correctness, security, and compliance with our style guides before submitting.

* <mark>**Disclose AI use.**</mark>
<mark>If any part of your contribution was generated by AI, mention it in the PR description</mark>
<mark>(e.g., "Co-authored with Claude" or "Generated with GitHub Copilot").</mark>
  This applies to code produced by chat-based AI assistants, agentic coding tools,
<mark>or any workflow where AI generated new logic or structure.</mark>
<mark>You do **not** need to disclose minor AI-assisted actions like Next Edit Suggestions (NES),</mark>
  single-line completions, or automated refactorings —
  these are essentially developer-driven edits with AI acceleration.

* **Do not submit AI output blindly.**
  Ensure you understand the code you are contributing.
  Reviewers may ask you to explain any part of your submission.

* <mark>**AI-generated tests must be verified.**</mark>
  Make sure generated tests actually validate meaningful behavior and are not just superficially passing.
