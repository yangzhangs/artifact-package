### <mark>AI-Assisted Development</mark>

<mark>We welcome AI-assisted development:</mark>

- <mark>**Tools Accepted**: Claude, ChatGPT, GitHub Copilot, Cursor, etc.</mark>
- <mark>**Quality Requirement**: All AI-generated code must be reviewed and tested</mark>
- <mark>**Context Engineering**: Prefer context engineering over "vibe coding"</mark>
- <mark>**Transparency**: You may mention AI tools used, but it's optional</mark>
- **Responsibility**: You are responsible for code quality regardless of how it was created
