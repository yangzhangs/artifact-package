## <mark>AI Generated Code</mark>

<mark>Of course you can use AI tools to _help_ you write code (who can ban you from that?) but in this case, please make sure to:</mark>
- <mark>Manually review and test all AI-generated code before submitting it</mark>
- <mark>State clearly in the PR description which parts of the code were generated by AI tools</mark>
- <mark>Prefer small, focused AI-generated snippets over large chunks of code</mark>
- <mark>Ensure that AI-generated code adheres to the project's coding style and guidelines</mark>

> [!WARNING]
> <mark>If we find AI-generated code that is not reviewed or tested, we may ask you to remove it or even close the PR.</mark>
