# Replication Package

This package contains the data and code for the three research questions in the paper. Data and scripts are organized by RQ; shared inputs appear once, in the RQ that uses them.

## Structure

```
.

├── MODEL_RESULTS.md                   # all reported model results in one place
├── ETHICS.md                          # research-ethics statement for the two surveys

│   │   ├── repos_sampled_57331.csv    # repositories passing the inclusion criteria
```

## Environment

- Python 3.9+ with `pandas`, `numpy`, `matplotlib`, `scipy` (`pymysql` only for the optional adoption-date script)
- R 4.0+ with `lme4`, `lmerTest`

Run commands from the package root.

## RQ1: Characterization of AIPs

1. `data/rq1/repos_sampled_57331.csv` lists the repositories returned by SEART-GHS under the criteria in Section II.A.
2. `data/rq1/repos_with_contributing_18902.csv` lists those with a CONTRIBUTING.md file.
3. Screening:
   ```bash
   python scripts/rq1/keyword_screening.py --dl-dir <guideline_files> --export --output screening_results.csv
   ```
   `--dl-dir` accepts either a flat corpus of files named `{owner}_{repo}[{path}]_contributing.md` or one directory per repository named `{owner}__{repo}` that contains `CONTRIBUTING.md`. The guideline files themselves are not redistributed; `data/rq1/screening_candidates_1114.csv` records the candidates from the original run.
4. Manual verification yields `data/rq1/confirmed_repos_615.csv`. Stance and condition labels are in `data/rq1/aip_labels.csv`; policy text is in `data/rq1/aip_contents/`.
5. Stance distribution (Fig. 2):
   ```bash
   python scripts/rq1/plot_stance_distribution.py
   ```

## RQ2: Associations with contribution dynamics

1. The analysis panels in `data/rq2/panels/` are indexed by bin relative to each repository's verified adoption date. Re-deriving the dates with `scripts/rq2/detect_aip_first_date.py` requires the repository and pull-request records in a database, which is not redistributed; set `DB_HOST`, `DB_USER`, `DB_PASS`, and `DB_NAME` (or pass the matching options) before running it.
2. Tables IV and V:
   ```bash
   Rscript scripts/rq2/table_iv_v.R
   ```
   Reads `data/rq2/panels/main.csv`; writes `data/rq2/results/table_iv_v.csv` with coefficients, standard errors, p-values, and R²m/R²c.
3. Table VIII:
   ```bash
   Rscript scripts/rq2/table_viii.R
   ```
   Regenerates all six configurations from `panels/main.csv`, `exclusion_band15.csv`, `exclusion_band45.csv`, `exclusion_band60.csv`, `window5.csv`, and `window4.csv`; writes `data/rq2/results/table_viii.csv` with every coefficient and both R2 values for each configuration.
4. Merged versus rejected split:
   ```bash
   Rscript scripts/rq2/rdd_split_merged_rejected.R
   ```
   Writes `data/rq2/results/split_merged_rejected_coefficients.csv` with every coefficient and both R2 values.
5. Full coefficient tables:
   ```bash
   Rscript scripts/rq2/model_results.R
   ```
   Writes `MODEL_RESULTS.md` with all terms of every model in the layout of Tables IV and V.
6. Trend figures:
   ```bash
   python scripts/rq2/plot_rdd_trends.py
   ```

## RQ3: Enforcement and perceptions

1. Survey instruments are in `survey/`; anonymized responses are in `survey/responses/`.
2. Survey summary (Tables II, III, VI, VII; survey values in Findings 3 and 7):
   ```bash
   python scripts/rq3/survey_summary.py
   ```
   Prints the recomputed counts, denominators, and percentages to standard output.
3. Figures:
   ```bash
   python scripts/rq3/plot_compliance.py
   python scripts/rq3/plot_contributor_attitude.py
   ```
   These two scripts plot the percentages reported in the paper; `survey_summary.py` recomputes them from the response files.

## Notes

- **Control timing.** `panels/main.csv` carries the three scale controls at the AIP adoption date, and `table_iv_v.R` uses them; the coefficients in Tables IV and V are reproduced exactly. `panels/data_collection_controls.csv` carries the same outcomes with data-collection values and supports the check in Section VI.B. Running the script reproduces the δ, standard errors, p-values, and R²m/R²c values in Tables IV and V (repository random intercept, at-adoption controls, REML = FALSE).
- **Table VIII.** All six configurations are regenerated from the shipped panels by `scripts/rq2/table_viii.R`.
- **RQ3 percentages.** Single-choice items use respondents who answered as the denominator; multi-select items report the share of respondents selecting each option.
- No respondent names or email addresses are released.
