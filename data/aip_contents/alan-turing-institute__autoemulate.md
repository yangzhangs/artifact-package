## <mark>Use of AI Tools</mark>

<mark>AI tools are useful but contributors are responsible for any code or documentation they commit. Please do not commit code you do not understand. If you commit AI-generated code, ensure its correctness and be prepared to explain exactly what it does. You do not have to disclose if code was written by AI, but making it clear where and how you used AI may be useful for reviewers, especially if AI was heavily used in your contribution.</mark>
