### Commit Practices to Avoid

- <mark>Don't use AI-generated commit messages without review and editing</mark>
- Don't make vague commits like "bug fix" or "update"

---

### General Guidelines

- Use meaningful variable and function names
- Document complex algorithms or non-obvious code decisions
- <mark>**Avoid AI-generated comments** - we prefer contextual comments over</mark>
<mark>boilerplate generated by tools like Cursor or Copilot</mark>
