## <mark>AI Policy</mark>

<mark>*This policy was gratefully inspired by the AI policies of SciPy and scikit-image.*</mark>

We are a small developer team, and we enjoy reviewing and discussing code
<mark>written by other humans. We recognize that LLMs may be useful, but overall</mark>
prefer for contributions to be hand-written.

---

### Responsibility

<mark>You are responsible for all the code that you contribute, including the AI</mark>
generated code. You must understand and be able to explain the submitted code as
well as its relation with the surrounding code. It is not acceptable to submit a
patch that you cannot understand and explain yourself.

---

### Disclosure

<mark>You must disclose whether AI has been used to produce any code of your</mark>
pull-request. If so, you must document which tool(s) have been used, how they
<mark>were used, and specify what code or text is AI generated.</mark>

---

### Copyright

Contributors must own the copyright of any code submitted to rendercanvas. Code
<mark>generated by AI may infringe on copyright and it is your responsibility to not</mark>
infringe. We reserve the right to reject any pull requests where the copyright
is in question.
