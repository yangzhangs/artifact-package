## <mark>AI Assistance Notice</mark>

> [!IMPORTANT]
>
> AI-**assisted** code contributions are allowed but **must be disclosed** in your pull request.

<mark>If you use any kind of AI assistance (e.g., GitHub Copilot, ChatGPT, Claude, etc.) while contributing, you must:</mark>

1. <mark>**Disclose this in your PR description**, including the extent of AI usage (e.g., "Used Copilot for autocomplete" or "Consulted ChatGPT for algorithm design")</mark>
2. <mark>**Test your changes thoroughly** — you are responsible for understanding and validating the AI-generated code</mark>
3. **Be able to explain and defend the changes** — maintainers may ask questions about the implementation

**Example disclosure:**

> <mark>This PR was written with assistance from GitHub Copilot for boilerplate code.</mark>

Or:

> <mark>I consulted Claude to understand the CEL spec requirements, but wrote the implementation myself.</mark>

---

### What We Expect

- **Human accountability** — You must understand the code you're submitting
- <mark>**AI assistance ≠ AI generation** — We expect significant human involvement and oversight</mark>
- <mark>**Code only** — AI-generated documentation, commit messages, and PR descriptions should be reviewed and edited by you</mark>

---

### What We Don't Accept

- PRs where the contributor cannot explain or defend the implementation
- <mark>AI-generated responses in issues and discussions (please write in your own words)</mark>
- <mark>Completely AI-generated code with no human understanding or testing</mark>

> [!NOTE]
> <mark>Trivial AI features like tab completion don't need to be disclosed. When in doubt, disclose it.</mark>

<mark>Failure to disclose AI assistance is disrespectful to maintainers and makes it difficult to properly review your contribution. Please be transparent!</mark>
