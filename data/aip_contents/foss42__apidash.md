## <mark>AI Usage Policy</mark>

<mark>We welcome the responsible use of AI tools (e.g., code assistants, LLMs, copilots) to improve productivity, learning, and developer experience. However, contributors are fully accountable for all submitted work.</mark>

---

### Acceptable Use

- <mark>AI tools may be used for **ideation, refactoring, debugging, new feature code generation, documentation, and test generation**.</mark>
- AI can assist in exploring, but must not replace understanding.

---

### Contributor Responsibility

- **You must understand the code you submit.**
<mark>Do not contribute AI-generated code you cannot explain, maintain, or debug.</mark>
- All contributions **must meet the same review bar as human-written code**.
- **You are responsible for correctness, security, performance, and maintainability**, regardless of how the code was produced.
- Ensure your contributions comply with our project's license.
- <mark>Do **not** submit AI-generated content that may:</mark>
  - Reproduce copyrighted or proprietary code
  - Violate third-party licenses
  - Include text or code with unclear provenance
- When in doubt, rewrite the code in your own words or consult maintainers.
- <mark>Review AI-assisted code for:</mark>
  - Hidden bugs or incorrect assumptions
  - Security vulnerabilities
  - Inconsistent style or architectural violations
- <mark>If a contribution is AI-assisted, **mentioning it in the PR description** is encouraged, especially for large or complex changes.</mark>
- You are prohibited from:
  - Blindly copying AI output without review
  - <mark>Using AI to bypass project guidelines, reviews, or contributor responsibilities</mark>

> AI is a tool, not an author. Use it to move faster—but think, verify, and take ownership of what you ship.
