## <mark>AI contribution policy</mark>

<mark>AI tools are greatly encouraged in advancing Walrus as a product and technology. However, humans are</mark>
fully responsible for everything that gets merged.

---

### Rules

- <mark>PR creators must review and understand all AI-generated changes before requesting review.</mark>
- <mark>Any AI-generated code touching production must be carefully reviewed by the PR creator.</mark>
- AI can create PRs and leave review comments.
- AI must **not** approve PRs. Only humans can approve and merge code.
- <mark>Extensive AI-generated tests are welcome, but the PR creator must</mark>
  ensure tests are easy to read and include clear, detailed descriptions so reviewers can quickly
  understand intent.

<mark>Given how fast AI is evolving, we plan to revisit these rules as things change. Let's use AI</mark>
aggressively, but take full ownership of what we ship.
