## <mark>AI Assistance Policy</mark>

<mark>Using AI assistants (GitHub Copilot, Claude, ChatGPT, etc.) is permitted when contributing to this project. However:</mark>

- <mark>**You are fully responsible for all code you submit**, whether written manually or AI-generated</mark>
- <mark>Thoroughly review and test any AI-generated code before committing</mark>
- <mark>Ensure AI-generated code follows the project's style and conventions</mark>
- Verify that AI suggestions are appropriate for the specific context
- <mark>Do not blindly accept AI suggestions without understanding them</mark>

Remember: AI assistants are tools to enhance productivity, not substitutes for understanding the code you're contributing.
