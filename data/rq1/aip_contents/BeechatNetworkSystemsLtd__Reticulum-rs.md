### <mark>Use of AI tools</mark>

<mark>It is common nowadays to use AI tools for syntax completion, to generate boilerplate, to find common and trivial bugs etc, and these uses of AI are encouraged for Reticulum-rs contributions too.</mark>

<mark>However, we do not see full-scale code generation ("vibe coding") in its current stage of development as appropriate for collaboratively written software such as ours. Contributions still need to be reviewed manually, and large generated PRs can become disruptive for a small team like ours. Therefore, **please do not submit vibe coded PRs**, not even if they pass all the vibe coded tests.</mark>
