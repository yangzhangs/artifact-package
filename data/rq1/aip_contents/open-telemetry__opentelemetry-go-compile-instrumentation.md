# <mark>AI Usage Policy</mark>

<mark>This project follows the [OpenTelemetry Generative AI Contribution Policy][otel-genai-policy].</mark>
Read and understand that document first — it is the canonical reference for all OpenTelemetry
repositories.

The sections below add project-specific guidance for `opentelemetry-go-compile-instrumentation`.

## The Critical Rule

**You must understand every line of code you submit.**

If you cannot explain what your changes do and how they interact with the broader system without
<mark>the aid of AI tools, do not contribute those changes. Using AI to write code is fine. Submitting</mark>
<mark>AI-generated output that has not been understood, reviewed, and owned by a human is not.</mark>

The fundamentals of software engineering have not changed. We still need carefully structured,
readable, and maintainable code backed by good tests. The quality of any contribution depends on
the quality of the thinking behind it, not the tool used to write it.

## Interactions on GitHub

Issue comments, pull request reviews, and any other communication on this repository are for
<mark>humans only. Never post AI-generated content directly to issues, PRs, or discussions without</mark>
<mark>thorough human review and editing. The content must be your own words, even if AI helped you draft</mark>
them.

<mark>AI code review tools configured by the repository maintainers (e.g. GitHub Copilot code review) are</mark>
an exception — those are expected and welcome.

## Further Reading

- <mark>[OpenTelemetry Generative AI Contribution Policy][otel-genai-policy].</mark>
- <mark>[Linux Foundation Generative AI Policy](https://www.linuxfoundation.org/legal/generative-ai) — foundation-wide guidance on contributing AI-generated code to LF projects.</mark>
- [Define policy around acceptable contribution guidelines](https://github.com/open-telemetry/community/issues/3256) — community discussion on managing low-effort contributions.
- <mark>[OpenTelemetry Collector AGENTS.md](https://github.com/open-telemetry/opentelemetry-collector/blob/main/AGENTS.md) — AI contribution guidelines from a sibling project.</mark>
- [Agentic Engineering Patterns](https://simonwillison.net/guides/agentic-engineering-patterns/) — patterns for getting the best results from coding agents.
- <mark>[Oxide RFD 0576: Using LLMs at Oxide](https://rfd.shared.oxide.computer/rfd/0576) — a thoughtful treatment of AI usage values: responsibility, rigor, empathy, teamwork.</mark>
- <mark>[Go project: What should we do with CLs generated by AI?](https://groups.google.com/g/golang-dev/c/4Li4Ovd_ehE/m/8L9s_jq4BAAJ) — the Go community's discussion on AI tooling, quality expectations, and legal considerations.</mark>

<mark>[otel-genai-policy]: https://github.com/open-telemetry/community/blob/main/policies/genai.md</mark>
